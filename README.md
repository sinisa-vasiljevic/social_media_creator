# Fußball Social Creator
Alle Dateien direkt in das Stammverzeichnis eines GitHub-Repositories hochladen. Danach unter **Settings → Pages** die Veröffentlichung aus dem Branch `main` und `/(root)` aktivieren. Die GitHub-Pages-Adresse am Handy öffnen und **Zum Home-Bildschirm** beziehungsweise **App installieren** wählen.
