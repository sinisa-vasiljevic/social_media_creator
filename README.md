# Fußball Social Creator

Alle Dateien dieser ZIP gehören gemeinsam in das Stammverzeichnis des GitHub-Repositories.

## GitHub Pages
1. ZIP entpacken und alle enthaltenen Dateien direkt in das Repository hochladen.
2. In GitHub unter **Settings → Pages** die Quelle **Deploy from a branch** wählen.
3. Branch **main** und Ordner **/(root)** auswählen.
4. Die GitHub-Pages-Adresse am Handy öffnen.
5. Im Browser **Zum Home-Bildschirm** oder **App installieren** wählen.

Die KI-Freistellung benötigt beim ersten Einsatz Internet. Die App selbst wird als PWA zwischengespeichert.
